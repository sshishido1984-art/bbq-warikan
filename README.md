# みんなの割り勘

旅行・飲み会・イベントなどの立て替えを、参加者が各自のスマホから入力して割り勘するWebアプリです。ログインは不要です。

- 画面：GitHub Pages（`index.html` / `style.css` / `app.js`）
- データ：Firebase Cloud Firestore（無料のSparkプランで足ります）

## 使い方

1. トップページでイベント名を入れて「作成」を押す
2. 出てきた共有リンクをLINEで送る
3. メンバーを追加する。名前の代わりに人数（例：5）を入れると、A〜Eの5人をまとめて追加できる。名前はあとから押して変えられる
4. 各自が「あなたは」で自分の名前を選び、支払ったものを入力する
5. 精算レシートの「精算結果をコピー」をLINEに貼る

品目ごとに「対象」から人を外せます（お酒を飲まない人、途中参加の人など）。

## 割り方は2種類

- **品目ごと**：品目ごとに「対象」から人を外せます。対象になった人で均等に分けます
- **全体で一律**：支払いの合計を全員で分けます。人ごとに「負担割合」を変えられます（基準は1。0.5で半分、2で倍、0で負担なし）

## Firebase の設定

1. https://console.firebase.google.com/ でプロジェクトを作成（Googleアナリティクスはオフで可）
2. 「Firestore Database」→「データベースを作成」→ 場所は `asia-northeast1`（東京）、本番環境モード
3. Firestore の「ルール」タブに `firestore.rules` の中身を貼り付けて公開
4. 「プロジェクトの設定」→「マイアプリ」→ ウェブアプリ（`</>`）を追加し、表示された `firebaseConfig` の値を `firebase-config.js` に貼る

`firebase-config.js` の値は公開されても問題ない識別子です。データの保護は `firestore.rules` で行っています。

## セキュリティについて

- イベントごとのページは推測できないランダムなIDで区切られ、全イベントの一覧は取得できません
- ただしリンクを知っている人は誰でも入力・削除ができます。リンクは参加者の間だけで共有してください
- 保存できる項目と文字数・金額はルールで制限しています

## Firebase 未設定のとき

`firebase-config.js` が初期値のままだと「動作確認モード」になり、入力はその端末にだけ保存されます。
